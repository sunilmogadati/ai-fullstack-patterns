Redux Toolkit: Basic JavaScript Web App

A basic JavaScript web app. No React. Open the browser DevTools console to see the store in action.

Steps performed

  1. Created the store with configureStore
  2. Subscribed to log every state change
  3. Dispatched comments/addComment twice
  4. Dispatched comments/likeComment
  5. Dispatched users/signIn
  6. Dispatched comments/removeComment
  7. Dispatched comments/fetchComments (async thunk: pending then fulfilled)
  8. Unsubscribed
